# 自动打招呼（有人进入视野 → 说话 + 点头）

小车停在帐篷里，前置摄像头看到人并停留约 1 秒后，主动说一句「你好呀～」并点个头。
同一场景 3 分钟内不会重复，夜间自动闭嘴，网页上可一键关闭。

> 设计推演与选型对比见 [自动打招呼方案.md](自动打招呼方案.md)，这份是**操作手册**。

## 1. 开箱即用

```bash
cd pi_client
git pull
# 重启服务（start_all.sh 或你平时的方式）
```

重启日志里应该有两行：

```
✓ 自动打招呼已就绪：启用（检测器=hog，语音=tts，时段=08:00-22:00）
打招呼：本地音频池为空（.../assets/greetings），将使用云端 TTS
```

打开控制台页面，右侧「自动招呼」面板能看到状态。点 **试一次（立刻打招呼）** 验证
扬声器和动作，不用真的站在摄像头前。

### 检测器会怎么选

| 条件 | 后端 | 说明 |
| --- | --- | --- |
| `models/yolo11n.onnx` + `onnxruntime` | `yolo` | 最快、最准 |
| `models/yolo11n.onnx`（没装 onnxruntime） | `yolo` | 走 `cv2.dnn`，**只要有 opencv 就行** |
| 没有模型，OpenCV 4.x | `hog` | 零额外依赖，能跑但精度一般 |
| 没有模型，OpenCV 5.x | `none` | **5.0 移除了 `HOGDescriptor`**，必须放模型 |

所以**最省事的组合是：只放一个 ONNX 模型文件**，不用 pip 装任何东西。见第 4 节。

## 2. 语音从哪来

两条来源，按 `greeting.speech.mode` 决定：

| 模式 | 行为 | 适用 |
| --- | --- | --- |
| `auto`（默认） | 有本地音频就用本地，没有就用云端 TTS | 推荐 |
| `pool` | 只用 `assets/greetings/*.wav` | 断网环境 |
| `tts` | 只用云端 TTS（结果会缓存） | 文案要动态 |
| `off` | 不发声，只做动作 | 调试 |

### 生成本地音频池（强烈建议）

营地信号不稳，云端 TTS 掉了会很尴尬。生成一次，之后断网也能打招呼：

```bash
cd pi_client
QWEN_API_KEY=sk-xxx python scripts/gen_greeting_voices.py
# 换音色 / 自定义文案
python scripts/gen_greeting_voices.py --voice longwan --text "你好呀～" --text "进来坐坐？"
```

产物是 `assets/greetings/greet_01.wav` + `manifest.json`（文件名 → 原文）。
重启后日志会变成「语音=pool」，运行时零延迟、零网络。

不想用 TTS 也行：自己录几段 16k 单声道 wav 丢进那个目录即可（其它采样率会自动重采样）。

## 3. 网页与 MCP 上的开关

| 入口 | 操作 |
| --- | --- |
| 网页「自动招呼」面板 | 右上角按钮开关；「试一次」手动触发；下面显示状态/判定原因/最近事件 |
| `GET /greeting/status` | 完整状态（检测器后端、语音来源、当前状态、最近事件） |
| `POST /greeting/enabled` | `{"enabled": false}` 运行时开关 |
| `POST /greeting/test` | `{"text": "可选文案"}` 立刻招呼一次 |
| MCP `greeting_status` | AI 问「小车现在会自动打招呼吗」 |
| MCP `greeting_test` | 让车立刻招呼一次 |
| MCP `set_greeting_enabled` | 开关 |

网页开关只写在内存里，**重启后回到 `config/default.json` 的值**。

## 4. 想要更准：换上 YOLO

HOG 只能识别「全身、正背、光线正常」的人，帐篷里有人半坐、逆光就容易漏。
而且 OpenCV 5.0 起已经没有 `HOGDescriptor` 了，5.x 上**必须**有模型才能检测。

```bash
# ① 在电脑上导出（不要用 Pi，torch 太大）
pip install ultralytics
yolo export model=yolo11n.pt format=onnx imgsz=320 opset=12

# ② 拷到 Pi
scp yolo11n.onnx bobo@<pi>:~/moyurobot/pi_client/models/
```

**就这样，不用装别的。** 有 `onnxruntime` 会优先用（更快），没有就走 `cv2.dnn`。

想再快一点再装：

```bash
pip install onnxruntime      # Pi 上约 40MB
```

日志里检测器会变成 `yolo`，并在括号里标出用的是 onnxruntime 还是 opencv dnn。

## 5. 调参对照表

都在 `config/default.json` 的 `greeting` 段，也都能用 `GREETING_*` 环境变量覆盖。

| 参数 | 默认 | 什么时候改 |
| --- | --- | --- |
| `min_person_ratio` | `0.30` | 人还远就开始招呼 → 调大（0.45 ≈ 3.6 米内）；走到跟前才招呼不出来 → 调小 |
| `center_zone` | `0.70` | 有人从旁边路过也被招呼 → 调小到 0.5 |
| `detect_fps` | `4` | Pi 4 上 CPU 吃紧 → 降到 2~3 |
| `trigger_frames` | `3` | 一闪而过的人也被招呼 → 调到 4~5，但响应会慢一点 |
| `leave_seconds` | `8` | 人只是转个身就被当「离开」→ 调大到 15 |
| `cooldown_seconds` | `180` | 同一个客人反复被招呼 / 想更热情 → 调小 |
| `max_per_hour` | `6` | 营地人来人往太吵 → 调小到 2~3 |
| `active_hours` | `08:00-22:00` | 夜里有人上厕所路过不想被招呼 → 已经在 22:00 停；要更早收工改成 `09:00-20:00` |
| `gesture` | `nod` | 想用摇头 `shake_head`，或只说话 `none` |
| `gesture_delay_ms` | `600` | 动作和语音抢拍（话还没出口就点头）→ 调到 1000 |
| `GREETING_GAIN` | `0.8` | 太吵/太轻（相对对讲音量） |

### 播放顺序

```
人进入画面 → 连续确认 ~0.75s → 出声（预录 <50ms / 云 TTS 0.8~1.5s）
                                 └ 0.6s 后开始点头（与语音并行）
```

## 6. 它不会抢谁的东西

三处资源都做了仲裁，出问题时会**跳过**而不是硬抢：

| 资源 | 规则 |
| --- | --- |
| 喇叭（对讲） | 有人按住说话时最多等 3 秒（`intercom_wait_s`），还占用就放弃本次语音。绝不打断人的说话 |
| 机械臂（动作） | 有动作正在播时**只出声不动手**（`respect_arm_busy`）。因为 `ActionPlayer.play()` 会直接打断别人正在做的动作 |
| 摄像头帧 | 检测器、网页 MJPEG、云端拍照共用同一个读取器（`FrameBroker`），不再互相偷帧 |

另外：打招呼播放期间，网页「监听车端」会被现有半双工逻辑自动静音（防啸叫），属正常现象。

## 7. 排错

| 现象 | 原因 / 处理 |
| --- | --- |
| 面板显示「未启动」 | 启动时加了 `--no-greeting`，或 `GreetingConfig` 加载失败。看日志里「自动打招呼」那行 |
| 状态一直是「待机」，人站在前面也不变 | ① 检测器 `none`：看面板「检测器」和日志的降级原因；若是 `当前 opencv 5.x 没有 HOGDescriptor`，放一个 `models/yolo11n.onnx` 即可；② 人太远：面板会显示「判定: 人太远」；③ 摄像头不是 `front`：查 `GREETING_CAMERA` |
| 状态显示「有人 / 准备招呼」但不出声 | 语音来源 `none`。要么生成音频池（第 2 节），要么配 `QWEN_API_KEY` |
| 出声但音箱没声音 | 对讲能听到车端声音吗？不能就是 `aplay` 设备选错，用网页「设备与自检」换扬声器 |
| 点头动作顿住 / 很生硬 | 确认走的是 `ActionPlayer`（`config/actions.json` 的 `nod`），不是 `nod_head()`。后者是裸 `set_arm_position` |
| 一直不重复招呼 | 正常：3 分钟冷却 + 每小时 6 次上限。要测就连按「试一次」（手动触发不看冷却） |
| 日志里每帧一行 | 默认 INFO 不会逐帧打。真要看调试就 `--log-level DEBUG`，记得日志治理会限速 |

## 8. 隐私

默认**不保存任何画面**（`snapshot_dir` 为空）。营地是半公共场所，长期留存陌生人的影像没必要
也麻烦；真要调试再临时设 `GREETING_SNAPSHOT_DIR=/tmp/greet`，顺手提醒：如果长期对着公共区域，
放个「本区域有摄像设备」的小牌子比较稳妥。
